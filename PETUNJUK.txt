VORTEX PROJECT — VERSI SIMPEL
================================

ISI FOLDER
----------
index.html   -> halaman welcome (splash, teks besar, info pembuat)
main.html    -> halaman koleksi proyek (search, filter, grid)
style.css    -> tampilan (tema ungu-hitam glow)
script.js    -> logika splash screen, search, filter, render kartu
data.txt     -> daftar proyek kamu (paling gampang diedit)

Kedua halaman punya navigasi "Beranda / Proyek" di paling atas buat
pindah-pindah.

ISI LINK TELEGRAM & TIKTOK
----------------------------
Buka index.html, cari 2 baris ini (ditandai komentar):

  <!-- GANTI href DI BAWAH INI DENGAN LINK TELEGRAM KAMU -->
  <a href="#" class="creator-link" ...>

  <!-- GANTI href DI BAWAH INI DENGAN LINK TIKTOK KAMU -->
  <a href="#" class="creator-link" ...>

Ganti href="#" jadi link asli, contoh:
  href="https://t.me/username_kamu"
  href="https://tiktok.com/@username_kamu"

CARA TAMBAH SCRIPT
-------------------
Buka data.txt, tambah blok baru di paling bawah, format:

nama=Nama Script Kamu
thumbnail=https://url-gambar.png
link=https://link-tujuan.com
codetype=Python
note=Deskripsi singkat script ini

Kosongkan 1 baris sebelum blok berikutnya.

codetype boleh diisi lebih dari satu, pisahkan dengan koma, contoh:
codetype=Python, JavaScript

Klik kartu di halaman Proyek akan membuka popup berisi Nama, Code Type,
Note, dan tombol ungu "Buka Link" di tengah bawah yang mengarah ke link.

CARA TES DI KOMPUTER/HP
-------------------------
File data.txt dibaca pakai fetch(), jadi TIDAK bisa dibuka langsung
dengan klik 2x index.html (browser akan blokir karena mode file://).
Harus dijalankan lewat server lokal kecil, contoh:

  python -m http.server 8000

lalu buka http://localhost:8000 di browser.

Kalau langsung di-deploy ke Vercel/GitHub Pages, ini otomatis jalan
normal karena sudah lewat http/https — tidak perlu langkah di atas.

DEPLOY KE VERCEL
------------------
1. Upload semua file ini (index.html, main.html, style.css, script.js,
   data.txt) ke repo GitHub kamu (bisa pakai auto_upload.py).
2. Buka vercel.com -> Add New Project -> Import repo itu.
3. Framework Preset pilih "Other" (situs statis biasa) -> Deploy.
4. Selesai, situs online. Halaman awal otomatis index.html.

UPDATE PROYEK SETELAH ONLINE
-------------------------------
Edit data.txt langsung di GitHub (tombol pensil) -> Commit.
Refresh halaman main.html, data baru langsung muncul (fetch selalu
ambil data.txt versi terbaru, tidak di-cache).
